# Statistics & Probability Cheatsheet

| Concept | Formula |
|---|---|
| Mean | sum(values) / count |
| Variance | sum((x - mean)²) / count |
| Std Dev | √variance |
| Probability | favorable outcomes / total outcomes |
| Independent events (AND) | P(A) × P(B) |
| Bayes' Theorem | P(A\|B) = [P(B\|A) × P(A)] / P(B) |

## When to use what
- Median over mean → when data has outliers
- Bayes' theorem → updating a probability given new evidence (e.g. Naive Bayes)
- CLT → why sample means behave normally even from non-normal data
